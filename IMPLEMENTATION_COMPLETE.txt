DATABASE SCHEMA
================================================================================

TABLE: employee_assets
  - id (bigint unsigned, PK)
  - employee_id (bigint unsigned, FK)
  - product_id (bigint unsigned, FK)
  - assigned_date (date)
  - returned_date (date, nullable)
  - status (enum: assigned, in_use, returned, damaged)
  - notes (text, nullable)
  - created_at, updated_at (timestamps)
  - Unique: (employee_id, product_id)
  - Indexes: employee_id, product_id

ROUTES STRUCTURE
================================================================================

Employee Management:
  GET    /employees/create              → 4-step wizard form
  POST   /employees                     → Store employee + assets
  GET    /employees/{id}                → Profile with assets

Asset Operations:
  GET    /employee-assets/{id}/return   → Return form
  PUT    /employee-assets/{id}/return   → Process return
  GET    /employee-assets/{id}/damage   → Damage form
  PUT    /employee-assets/{id}/damage   → Process damage

Dashboard:
  GET    /assets/dashboard              → Main dashboard
  GET    /assets/export                 → Export all assets
  GET    /assets/by-status/{status}    → Filter by status
  GET    /assets/by-department/{dept}   → Filter by department

Reports:
  GET    /asset-reports/utilization    → Utilization report
  GET    /asset-reports/export-utilization → Export utilization
  GET    /asset-reports/damage         → Damage report
  GET    /asset-reports/export-damage  → Export damage
  GET    /asset-reports/employee-allocation → Allocation report
  GET    /asset-reports/export-employee-allocation → Export allocation

================================================================================
USAGE EXAMPLES
================================================================================

Example 1: Create Employee with Assets
  1. Go to /employees/create
  2. Step 1: Enter basic info (name, code, department, role)
  3. Step 2: Enter employment details
  4. Step 3: Enter salary information
  5. Step 4: Select assets (computer, tools, etc.)
  6. Submit → Employee created with linked assets

Example 2: Return Asset
  1. View employee profile
  2. Click return button on asset
  3. Enter return date and condition
  4. Add notes and receiver name
  5. Submit → Asset status becomes "Returned"

Example 3: Report Damage
  1. View employee profile
  2. Click damage button on asset
  3. Select severity (Minor/Moderate/Severe)
  4. Select cause (Accidental/Misuse/etc)
  5. Describe damage and get acknowledgment
  6. Submit → Asset status becomes "Damaged"

Example 4: View Reports
  1. Go to Asset Management dashboard
  2. Click Reports dropdown
  3. Select report type
  4. View data and download CSV
