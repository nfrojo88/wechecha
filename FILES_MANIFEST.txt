================================================================================
                          INTEGRATION POINTS
================================================================================

WHERE SEQUENCE IS USED:
  app/Http/Controllers/StoreManagerController::storeSlip()
  
  When slip created:
    1. Check if manual slip_no provided
    2. If empty: Get sequence
    3. Call: $sequence->generateSlipNumber()
    4. Use returned number as dr_no
    5. Save slip with auto-generated number

RELATIONSHIPS:
  SlipSequence -> Store (many-to-one)
  Store -> SlipSequence (one-to-many)

MODEL CALLS:
  SlipSequence::where('store_id', $id)
             ->where('slip_type', 'receive')
             ->where('status', 'active')
             ->first()
             ->generateSlipNumber()
