================================================================================
                         HOW IT WORKS (SIMPLE)
================================================================================

BEFORE:
  Manual entry of slip numbers → Risk of gaps, duplicates, or out-of-order

AFTER:
  1. Store Manager configures sequence (e.g., REC 2100-2150)
  2. User creates slip (leaves "Slip No" blank)
  3. System auto-assigns: REC02100, REC02101, REC02102, etc.
  4. Dashboard shows: 3/51 used (5.88%), 48 remaining
  5. When book full: Status changes to "Full"

MANUAL OVERRIDE:
  Can still manually enter slip number if needed (optional)

================================================================================
                            KEY FEATURES
================================================================================

AUTO-NUMBERING FORMATS:

  With Prefix "REC":
    REC02100  →  REC02101  →  REC02102  → ... → REC02150

  Without Prefix (Numeric):
    02100  →  02101  →  02102  → ... → 02150

BOOK MANAGEMENT:

  Range: 2100-2150
  Total: 51 slips
  Progress: Visual bar showing % used
  Status: Active (in use) / Inactive (paused) / Full (exhausted)

DASHBOARD:

  ✓ View all sequences at once
  ✓ See usage progress for each
  ✓ Know next slip number
  ✓ Quick action buttons (Edit, Pause, Resume)
  ✓ Remaining slips counter

DATABASE:

  ✓ One table: slip_sequences
  ✓ 9 columns: store_id, slip_type, label, prefix, book_start_no, book_end_no,
              current_slip_no, used_count, status
  ✓ Unique constraint: prevents multiple active sequences per store+type
  ✓ Indexed for performance

================================================================================
                         SUPPORT & TROUBLESHOOTING
================================================================================

COMMON ISSUES:

1. Migration Error "Column not found"
   → Check delivery_receipts table has correct schema
   → Verify database connectivity

2. "No active slip sequence configured" Error
   → Create a sequence first via "Configure New Sequence"
   → Make sure status = "active"

3. Slip number not incrementing
   → Verify sequence status is "active"
   → Check you're in same store as sequence
   → Check slip_type matches sequence type

4. Sidebar menu not showing
   → Clear browser cache
   → Logout and login
   → Check user role (Store Manager/Admin required)

================================================================================
                           QUICK REFERENCE
================================================================================

SLIP TYPE:
  receive (GRN) = Goods Received Note = Supplier deliveries
  send (SIN)    = Store Issue Note    = Material transfers

BOOK FULL:
  When all slips in range assigned → Status becomes "Full"
  Cannot assign more → Must create new sequence for next book

PREFIX EXAMPLES:
  "REC" → REC02100, REC02101, REC02102
  "OUT" → OUT01501, OUT01502, OUT01503
  (blank) → 02100, 02101, 02102

DATABASE CONSTRAINT:
  Only ONE active sequence per (store_id, slip_type) combination
  Prevents confusion about which sequence to use

ZERO-PADDING:
  Numbers are always 5 digits with leading zeros
  2100 → 02100 (for consistent formatting)
